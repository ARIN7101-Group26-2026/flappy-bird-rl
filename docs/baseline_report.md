# 第一阶段验收：环境 + Random

验收日期：2026-10-24（Asia/Shanghai）。本报告来自实际执行，未使用模拟统计数据。

## 实验配置

- Linux x86_64，CPython 3.10.12；依赖精确版本见 `requirements-lock.txt`。
- `FlappyBird-v0`，12 维归一化数值状态，原始奖励，管道间隙 100，单局上限 5000 步。
- 每组 100 局；验证环境种子 1000–1099；动作种子为环境种子加 1000000。
- 共 400 局。本次没有运行最终测试集，也没有选择或训练 DQN/PPO 模型。

复现命令：

```bash
python -m flappy_bird_rl random --env-config configs/env.json --config configs/random.json
```

## 实际结果

| 拍翅膀概率 | 局数 | 平均过管数 | 过管数样本标准差 | 最高过管数 | 平均存活步数 | 平均累计奖励 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 0.50 | 100 | 0.000 | 0.000 | 0 | 50.00 | -7.650 |
| 0.20 | 100 | 0.000 | 0.000 | 0 | 50.17 | -0.391 |
| 0.10 | 100 | 0.070 | 0.256 | 1 | 51.12 | 3.682 |
| 0.05 | 100 | 0.050 | 0.219 | 1 | 45.97 | 3.524 |

四组得分中位数均为 0。400 局全部因环境死亡终止，步数上限截断次数为 0。逐局 CSV 仍保留两种结束标志，以便后续模型能存活到时间上限时正确统计。

在这组验证种子上，`p=0.1` 有 7 局通过 1 根管道，`p=0.05` 有 5 局通过 1 根管道。差距很小，不能据此宣称 `p=0.1` 在总体上最优。均值图的误差线表示回合得分的样本标准差，不是置信区间；不同概率的回合使用配对种子。

高拍翅膀频率会使鸟反复触顶，上游环境存在触顶惩罚，因此 `p=0.5` 的累计奖励可为负。奖励和管道得分是不同指标：本项目直接记录 `info["score"]`。
